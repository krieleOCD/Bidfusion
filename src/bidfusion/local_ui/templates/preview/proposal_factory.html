What this is, and what it is not

The stages below are a model of how a response would be produced. They are not running, and there is nothing here to start.

Current mode

  • Static workflow preview
  • No stage executes
  • No autonomous agent runtime exists

Fixed rules

  • No customer-facing text is generated from uploaded files
  • No model is called from this interface
  • Nothing reaches a customer unless a person sends it

Terminology

  • A "stage" is a step in a process a person drives
  • Naming a stage does not make it a running service
